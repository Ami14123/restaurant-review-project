# Restaurant Review Analysis Project

## Overview
This project performs an exploratory data analysis (EDA) on restaurant review data to understand customer sentiment and compare performance across various establishments.

## Pipeline
1.  **Preprocessing:** Load the dataset and handle non-numeric data entries (e.g., cleaning the 'Rating' column).
2.  **Exploration:** Analyze data structure and missing values to ensure the dataset is valid for analysis.
3.  **Visualization:** Generate visual insights, such as average ratings per restaurant, to identify trends and benchmarks.

## How to run
1. Ensure you have the required libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`, `tensorflow`, `tensorflow_text`.
2. Place `Restaurant reviews.csv` in the same directory as the notebook.
3. Run the cells in `Data_mining_project.ipynb` sequentially.
